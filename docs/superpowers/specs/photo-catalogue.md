# P91 Car Care: Photo Catalogue (honest audit)

Date: 2026-11-25. Source: `attached_assets/`. Every image listed below was opened and looked at. Descriptions are based on what the image shows; filenames were ignored.

**Scope:** `gallery/`, `about/`, `brands/`, `blog/`, `carousels/` (all subfolders), loose root `.jpg/.jpeg/.webp/.avif`, and `generated_images/` (checked for AI). **Not covered:** `_opt/`, `services/`, `reels/` posters, `stock_images/`, `offers/`, and root `.png` files other than the 3 screenshots checked.

**How to read the table**
- **"Real P91?"** means the photo shows P91's own studio (dark panelled bay with a grid of linear LED lights, the P91 / NASIOL / STEK wall signs, or the corrugated-sheet wash bay with a green grass wall), or it carries a P91 number plate.
- **Stock** means a generic web image (often with another company's watermark).
- **AI** means a generated render.
- A **P91 logo in the corner does not prove the photo is P91's own.** Several stock or third-party frames have the logo added.
- Quality values: hero-worthy / ok / poor. "IG screenshot" means the file was cropped from an Instagram post, sometimes with the carousel arrow still visible at the edge.
